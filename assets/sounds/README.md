# Push Notification Sound

You can add a custom notification sound file here.
- Supported formats: .wav, .mp3, .aiff
- Recommended duration: Under 30 seconds
- Recommended file size: Under 100KB

For now, the system will use the default notification sound.
You can download free notification sounds from:
- https://www.zapsplat.com/sound-effect-categories/notification-sounds/
- https://freesound.org/search/?q=notification

To add a sound:
1. Download or create a notification sound file
2. Save it as "notification.wav" in this directory
3. The app will use this sound for push notifications
